工程別に色を設定。今の工程がすぐわかる。 Set colors by step and see the current task instantly.

工程ごとに色とアイコンを分けられるので、作業中でも現在位置が一目でわかります。手が離せない場面では音声操作も活用できます。 Each step can have its own color and icon, making the current position easy to spot while you work. Voice control helps when your hands are busy.

02

同じ作業を、個別に工程管理。 Run the same workflow across separate sessions.

複数の対象を少しずつずらして進める作業も、1画面で見やすく管理できます。各セッションの進行状況を並べて確認できます。 When several items move through the same steps at different times, the multi-timer view keeps every session visible on one screen.

  • 複数タイマーを同時に実行Run multiple timers at once
  • セッションごとに状態を固定表示Keep each session status visible
  • 作業中の停止や一時停止も個別操作Pause or stop each session independently
